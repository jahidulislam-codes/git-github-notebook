# Git Documentation: Day 8 - GitHub & Remote Repositories

## Core Concepts

- **Remote Repository**: A version of your project hosted on the internet or network (e.g., GitHub).
- **Push**: Uploads local branch commits to a remote repository.
- **Pull**: Downloads and merges changes from a remote repository into your current local branch.
- **Clone**: Creates a local copy of a remote repository onto your computer.

## Key Commands

- **Connect Remote**: `git remote add origin <url>`
- **Push Code**: `git push -u origin main`
- **Clone Repo**: `git clone <url>`
- **Pull Changes**: `git pull`
- **Fetch Updates**: `git fetch`
